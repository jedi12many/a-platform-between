# Conditions (docs/conditions.md, docs/turn.md): what's true of a fighter for a while, or for
# good. Append only: an id, once shipped, never changes. Ids are 1..255.
#
# rounds:   how many of its bearer's turns it lasts (counted down at the end of each, but
#           not the turn it was put on), or - (until something ends it)
# shake:    STAT:TN, rolled at the end of its bearer's turn (d100 + the stat), or -
# opposite: the condition it cancels when it's put on (and that cancels it), or -
# then:     what it becomes when its rounds run out, or -
# tag:      a short name for the battle screen
# effects:  any of (N a whole number, TYPE kinetic energy fire cold mind, none if left out)
#   dot=N[:TYPE]   N damage at the start of each turn (no TYPE: Soak doesn't count)
#   heal=N         N health back at the start of each turn
#   speed=N        Speed up or down (only the worst penalty and the best bonus count)
#   speed0         can't move at all
#   dodge=N dodge0 armor=N ward=N soak=N   defenses up or down (dodge0: Dodge counts as 0)
#   rolls=N        every roll; attacks=N every attack roll; melee=N melee attack rolls
#   next=N         the next attack roll, then it ends
#   shake=N        rolls to shake off conditions
#   immune=A,B     those conditions never land; immune_hazard=TYPE: hazards' TYPE damage
#   lose_turn      no move, no action
#   down           knocked down: Dodge counts as 0; standing up takes half your Speed
#   ends_when_hit  ends when damage gets through; ends_on_heal: ends when healed
#   barrier=N      the next N damage is taken off before health, then it ends
#   vulnerable=TYPE  double damage of that type
#   thorns=N[:TYPE]  whoever hits you in melee takes N
#   no_powers      can't attack with a focus; no_heal: healing does nothing
#   fly            crosses pits, and rough ground costs 1; falls if it ends over a pit
#   first          acts first in the order of play
#   race=RACE      one of that race's two traits: always on
#
